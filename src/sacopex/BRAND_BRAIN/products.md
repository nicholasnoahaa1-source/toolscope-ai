## Regras para Novos Sabores

Quando adicionar um novo sabor, documentar:

1. **Nome oficial** — exato como será usado em marketing
2. **Descrição funcional** — o que é (biscoito, fruta, etc.)
3. **Ângulo de Marketing** — como vender (nostalgia, descoberta, saúde sofisticada, etc.)
4. **Público Alvo** — quem vai comprar
5. **Cor visual primária** — qual da paleta locked será acento (sempre uma das 4)
6. **Copy de referência** — exemplo de headline para este sabor

### Exemplo (Morango futuro)
```
| **Morango** | Sacolé de morango natural | Refrescância sofisticada, verão | Millennials, mulheres 25–35 |
```

## Contexto de Uso (ocasiões de consumo)

SacoPex é para:
- ✓ Pausa na tarde
- ✓ Refrescância após exercício
- ✓ Momento social com amigos
- ✓ Lembrança nostálgica com otimismo

SacoPex **não é para:**
- ✗ Refeição (não é nutritivo, é refrescância)
- ✗ Compensação ("coma meu sorvete porque você merece")
- ✗ Saúde (sem claims de vitamina, sem "sem açúcar" forçado)

---

## Embalagem e Assinatura

Cada produto deve carregar:
1. Nome do sabor (tipografia Manrope)
2. Texto "SacoPex" (assinatura, Manrope bold)
3. Paleta locked (4 cores apenas)
4. Nenhum ícone, nenhum símbolo gráfico

Não criar variações de design por sabor — o design é um, o sabor é o que muda via copy/imagem.
