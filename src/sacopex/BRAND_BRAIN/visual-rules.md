# Visual Rules — LOCKED

Todas as decisões visuais da SacoPex passam por estas restrições. Sem exceções.

---

## Paleta de Cores (4 cores, ponto final)

| Nome | Hex | Uso |
|------|-----|-----|
| **Creme** | `#F5F1EB` | Fundo principal, respiro visual |
| **Navy** | `#1A2B3E` | Tipografia, elementos principais |
| **Navy Tartaruga** | `#2D4A5C` | Tipografia secundária, contorno |
| **Laranja Pastel** | `#E89B7E` | Acento, CTA, destaque — *máximo 20% da composição* |

### Restrições
- ✗ Sem cores adicionais sem justificativa escrita
- ✗ Sem gradientes — cores sólidas apenas
- ✗ Sem inversão de paleta (creme nunca é Navy)
- ✗ Laranja nunca é fundo dominante
- ✓ Se precisa de uma quinta cor, deve estar documentada no arquivo de exceção (não criar sem avisar)

---

## Tipografia (2 famílias)

### Headlines (Manrope)
- **Manrope 800** — Títulos principais (26–48px)
- **Manrope 700** — Subtítulos, call-outs (16–24px)
- **Manrope 600** — Labels, affordances (12–16px)
- **Manrope 500** — Body enfático, números importantes

**Mínimo:** 16px para legibilidade em qualquer contexto

### Body (Tiempos Text Italic)
- **Tiempos Text Italic 400** — Descrições, narrativa, legenda
- **Tiempos Text Italic 500** — Ênfase dentro de body

**Mínimo:** 14px para corpo corrido; 12px para rodapés/avisos

### Sem Exceções
- ✗ Sem outras fontes (nenhuma Adobe, nenhuma local customizada)
- ✗ Sem weights fora do padrão (não usar Manrope 300, não usar Tiempos 300)
- ✗ Manrope nunca em itálico
- ✗ Tiempos nunca em normal (sempre italic)

---

## Logotipo e Assinatura

✓ **Assinatura permitida:** Texto "SacoPex" em Manrope bold  
✗ **Sem logo gráfico** — nunca criar símbolo, ícone ou marca verbal além do texto  
✗ **Sem símbolo** — sem sorvete, paleta ou nenhuma ilustração que represente "marca"  
✗ **Sem alteração** — não redesenhar, não reposicionar, não colorir diferente

---

## Composição Visual

### Espaçamento
- Mínimo de gutter lateral: **16px** em mobile, **28px** em desktop
- Entre elementos: **12–24px** (de acordo com hierarquia)
- Leading (line-height): **1.6–1.8** para body text

### Contraste
- Mínimo WCAG AA para todos os textos: **4.5:1**
- Navy sobre Creme: ✓ seguro
- Laranja sobre Creme: ✓ seguro
- Laranja sobre Navy: ✓ seguro

### Elementos Visuais
- ✓ Fotografias e still-lifes reais (produto, consumo, contexto)
- ✓ Texturas naturais (gelo, condensação, reflexos)
- ✓ Superfícies simples (creme, navy, laranja como fundo)
- ✗ Sem cliparts, emojis, ícones gráficos customizados
- ✗ Sem efeitos (glow, blur excessivo, glitch)
- ✗ Sem padrões geométricos (stripes, dots, grids)

## Aplicação em Redes

### Instagram
- Paleta: Creme fundo, Navy texto, Laranja acento
- Tipografia on-screen: Manrope bold (headlines); Tiempos italic (body)
- Estilo: Editorial, fotografia de qualidade, composição limpa

### TikTok
- Movimento ok, mas dentro da paleta (sem efeitos RGB, sem cores que fogem)
- Texto: Manrope bold para CTAs; Tiempos italic para narrativa
- Sem música com letra que contradiga o tom

### Stories
- Cards limpos: Creme ou Navy, tipografia contrastante
- Stickers: Apenas texto, sem gráficos customizados
- Timing: 3–5 segundos por card

### Anúncios
- Conformidade com políticas das plataformas (sem misleading, sem health claims)
- Tipografia clara e legível em thumbnail (mínimo 12px)
- CTA sempre legível (fundo e tipografia com contraste mínimo 4.5:1)

---

## Verificação Antes de Publicar

Cada asset passa por esta checklist:

- [ ] Apenas 4 cores (Creme, Navy, Navy Tartaruga, Laranja Pastel)
- [ ] Tipografia: Manrope ou Tiempos Text Italic (nenhuma outra)
- [ ] Sem logo gráfico ou símbolo criado
- [ ] Assinatura em texto "SacoPex" presente (se aplicável)
- [ ] Nenhum efeito visual que foge da paleta
- [ ] Contraste mínimo 4.5:1 para texto
- [ ] Nenhum claim de saúde, de comparação com concorrente
- [ ] Tom não é corporativo, não é brega, é sofisticado-jovem
