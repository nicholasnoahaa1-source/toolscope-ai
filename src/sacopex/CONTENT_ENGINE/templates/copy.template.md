# Copy Template

Estrutura para gerar copy alinhado com brand rules.

---

## Input (da Strategy)

```
Pilar: [ex: Ação imediata]
Ângulo: [ex: Nostalgia sofisticada]
Emoções: [ex: urgência, desejo]
Insight: [ex: Millennials buscam prazeres simples com qualidade]
Produto: [ex: Sacolé Oreo]
Sabor: [ex: Oreo]
Oferta: [ex: 2 por R$10]
CTA: [ex: Peça o seu]
```

---

## Copy Output

### 1. Big Idea (a frase que resume tudo)

**Estrutura:** [Quando/Se] + [emoção/insight] + [é a resposta]

**Exemplos:**
- "Quando sofisticação é simples"
- "Quando a nostalgia bate sofisticada"
- "Quando você quer qualidade sem drama"

**Checklist:**
- [ ] Máximo 10 palavras
- [ ] Usa Manrope bold quando on-screen
- [ ] Sem claims de saúde
- [ ] Reflete o ângulo da strategy

---

### 2. Hook (primeira frase que prende atenção)

**Estrutura:** [imperativo] + [benefício emocional]

**Exemplos:**
- "Oreo nunca foi tão sofisticado"
- "Lembra daquele sacolé? Agora ele cresce com você"
- "Aquele momento em que nostalgia é elegante"

**Checklist:**
- [ ] Máximo 15 palavras
- [ ] Verbo forte (no imperativo ou afirmação direta)
- [ ] Evoca a emoção da strategy
- [ ] Sem gírias forçadas

---

### 3. Main Copy (o argumento completo, 2–3 frases)

**Estrutura:**
1. Hook (ver acima)
2. Produto + Benefício + Oferta
3. Call to Action

**Exemplo completo:**
"Quando sofisticação é simples. Sacolé SacoPex traz qualidade, refrescância, sem compromisos. 2 por R$10. Peça o seu."

**Checklist:**
- [ ] Máximo 3 frases
- [ ] Hook > Benefício > CTA (ordem clara)
- [ ] Oferta é clara (preço, quantidade, timing)
- [ ] CTA em imperativo
- [ ] Sem pontos de exclamação em excesso

---

### 4. Short Description (50–80 palavras, para cards/stories)

Versão condensada do main copy, para contextos de espaço limitado.

**Estrutura:**
- Abertura emocional (1 frase)
- Produto + Benefício (1 frase)
- Oferta + CTA (1 frase)

**Exemplo:**
"Aquele momento em que a nostalgia bate sofisticada. Sacolé SacoPex: qualidade que você merecia, preço que você aprecia. Peça o seu — 2 por R$10."

**Checklist:**
- [ ] 50–80 palavras
- [ ] Estrutura 3-frase
- [ ] Legível em mobile

---

### 5. Long Description (para website/email, 150–200 palavras)

Versão narrativa, com mais contexto e detalhes.

**Estrutura:**
- Insight/emoção (1–2 frases)
- Produto + o que torna único (1–2 frases)
- Oferta + Onde comprar (1 frase)
- CTA (1 frase)

**Exemplo:**
"Há quem buscasse qualidade com leveza. Prazeres simples, mas bem-feitos. É por isso que SacoPex existe: transformar um clássico em um momento de prazer sem pressa. Cada mordida equilibra doçura e frescor, do jeito que só a SacoPex sabe fazer — sem inventar o que não precisa, sem prometer o que não entrega. 2 por R$10 [onde comprar]. Peça o seu antes que derreta."

**Checklist:**
- [ ] 150–200 palavras
- [ ] Narrativa fluída (não de lista)
- [ ] Oferta clara
- [ ] CTA ao final

---

### 6. Hashtags (3 sets de 3 tags cada)

**Regra:**
- Sempre com #SacoPex como first tag
- 2–3 tags adicionais por set
- Máximo 30 caracteres por set

**Set A (nostalgia):**
```
#SacoPex #SacolèQueSofistica #RefrescareComEstilo
```

**Set B (qualidade):**
```
#SacoPex #NostalgiaSofisticada #MomentosQueRefrescam
```

**Set C (oferta/ação):**
```
#SacoPex #SaborDeInfancia #VeraoSofisticado
```

**Checklist:**
- [ ] First tag sempre #SacoPex
- [ ] Sem gírias forçadas
- [ ] Relevantes para público (Millennials)
- [ ] Máximo 9 tags totais (3 sets × 3)

---

## Conformidade (Forbidden List Check)

Antes de finalizar, rodar contra regex:

```
❌ Health claims (emagrece, cura, saudável, diet)
❌ Slang forçado (mano, véi, slk, c'mon)
❌ Comparação (melhor que, diferente de)
❌ Promessas falsas (revolucionário, transforma vidas)
```

Se qualquer um passar, voltar e revisar.

---

## Format-Specific Notes

### Instagram Post/Feed
- Legenda: Main Copy + Set A Hashtags
- Alt-text: descrição do visual (sem claims)

### Story
- Copy: Hook + CTA (máximo 2 linhas)
- Hashtags: Set B

### TikTok/Reel
- Hook: nos primeiros 2 segundos
- Main Copy: texto on-screen em Manrope
- CTA: último card

### Carrossel
- Slide 1: Hook
- Slide 2–4: Benefícios/Oferta
- Slide 5: CTA + Hashtags
