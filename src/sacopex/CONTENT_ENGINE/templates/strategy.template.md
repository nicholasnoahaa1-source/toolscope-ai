# Strategy Template

Use este template para gerar estratégia antes de criar conceito/copy/visual.

---

## Input (do briefing)

```
Produto: [ex: Sacolé Oreo]
Sabor: [ex: Oreo]
Objetivo: [Venda / Engajamento / Awareness / Lançamento]
Público: [ex: Millennials urbanos, 25–38 anos]
Formato: [Reel / Story / Post / Carrossel / Campanha]
Oferta: [ex: 2 por R$10]
Tom: [ex: Jovem e sofisticado, com humor nostálgico]
CTA: [ex: Peça o seu antes que derreta]
```

---

## Strategy Output

### Pilar de Campanha
**Pilar:** [ex: Ação imediata]
- Define o objetivo macro: por quê o público deveria interagir agora?

### Ângulo (approach)
**Ângulo:** [ex: Nostalgia sofisticada — o clássico da infância, elevado]
- Como vamos falar sobre o produto? Qual perspectiva única?
- Deve ser diferenciante entre sabores/objetivos.

### Emoções-Alvo
**Emoções:** [ex: urgência, desejo, nostalgia positiva]
- Lista de 2–3 emoções que queremos ativar
- Usado para guiar copy/visual/music

### Insight de Público
**Insight:** [ex: Millennials buscam prazeres simples com acabamento de qualidade — quer se sentir bem tratado, não só bem alimentado]
- Uma frase que resume por quê o público vai se conectar com SacoPex
- Base para todos os outros módulos

### Ocasião de Uso
**Quando:** [ex: Pausa na tarde, refrescância pós-atividade, momento social]
- Contexto de consumo
- Influencia visual (luz, ambiente, timing)

---

## Verificação

Antes de passar para o próximo módulo (Creative Concept):

- [ ] Pilar alinha com objetivo (Venda → Ação Imediata, Lançamento → Expectativa, etc.)
- [ ] Ângulo é único (não é genérico "sorvete é bom")
- [ ] Emoções são todas positivas ou justificadamente tensas (nunca culpa)
- [ ] Insight reflete o tom de voz SacoPex (sofisticado-jovem)
- [ ] Ocasião de uso não força a narrativa de saúde/responsabilidade

| Objetivo | Pilar | Emoções | Ocasião |
