Analytics Engine

Coleta, armazenamento e análise de desempenho de conteúdo

Importar Métricas de Plataformas

Cole aqui os dados JSON exportados do Instagram Insights, Meta Ads Manager, TikTok Analytics ou outras plataformas. O sistema irá processar e armazenar localmente.

Mapeamento de URLs

Se os dados importados não tiverem contentIds, use esta seção para vincular URLs publicadas aos IDs das peças geradas.

Dados Coletados

Todos os dados são armazenados localmente no seu navegador (IndexedDB). Nenhum dado é enviado para servidores externos.

Nenhum dado coletado ainda. Comece importando métricas na aba "Importar Dados".

Análise de Padrões

O sistema analisa os dados coletados para identificar padrões de desempenho que informarão a próxima geração de conteúdo.

Insira mais dados (mín. 5 peças) para análise de padrões.

Recomendações para Próxima Geração

Recomendações aparecerão após análise de padrões.
